# Security policy

Kharcha processes sensitive financial SMS data. Please do not report a
security vulnerability in a public issue or include real SMS messages,
account numbers, transaction amounts, keystores, or passwords in any report.

Use GitHub's **Private vulnerability reporting** for this repository if it is
available from the repository's **Security** tab. If it is unavailable, contact
the maintainer privately through the [repository owner's GitHub profile](https://github.com/imkks).

Please include the affected component, impact, and steps to reproduce using
synthetic or redacted data. The maintainer will acknowledge the report and
coordinate a fix before public disclosure. No response-time guarantee is
currently offered.

## Supported versions

Security fixes are made on the current `main` branch.
