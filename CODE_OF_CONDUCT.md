# Code of Conduct

## Our standards

Everyone participating in Kharcha discussions and contributions is expected
to be respectful, constructive, and considerate of different backgrounds and
levels of experience.

Unacceptable behavior includes harassment, discrimination, personal attacks,
sharing another person's private information, or publishing real financial or
SMS data without consent.

## Applying these standards

Project maintainers may edit or remove contributions that violate this code
and may restrict participation when needed. To report a concern, contact the
maintainer privately through the [repository owner's GitHub profile](https://github.com/imkks).

This code applies to project spaces, including issues, pull requests, and
project discussions.
